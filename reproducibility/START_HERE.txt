ARIR-UAM: public archived-analysis reproduction bundle

Repository: https://github.com/tobylswang-dev/arir-uam

Run these commands from the reproducibility/ directory with Python,
numpy, pandas and scipy installed. ENVIRONMENT.json records the original
environment; local verification does not establish cross-platform equivalence.

1. Arithmetic/interface fixture:
   python review_example/run.py
2. Real 100-demand-set worked example:
   python reproduce_worked_example.py
3. Full stored-summary analysis:
   python arir.py --runs runs --output regenerated_report --events logs

The third command reads 43,200 stored simulation summaries and uses 4,000
bootstrap resamples. Compare regenerated_report/ with report/. It does not
rerun the simulation campaign. Only 24 selected joint runs have complete
stored request-scan logs; summary hashes cannot reconstruct missing histories.

The worked example uses seeds 20000-20099, demand 1, B=2, node=1 and link=1.5:
100 demand sets and 800 matched records. It checks the reported absolute means
and contrast decomposition, not the original 108-effect inferential family.

The separate R68_complete_source_and_data.zip is not included in this public
repository snapshot. Full simulator execution, independent-code checks and
the supplementary analyses require that separate archive. The upstream
implementation README and historical manifests describe its original layout;
they are provenance records, not an inventory of this smaller public bundle.
