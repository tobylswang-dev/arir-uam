# ARIR-UAM

Reproducibility code and archived analysis results for ARIR-UAM.

## Repository contents

The `reproducibility/` directory contains analysis code, worked
examples, archived summaries of 43,200 simulation runs, and
selected event logs.

## Reproducibility scope

This repository supports reconstruction of the archived analyses.
Reconstructing these analyses is not equivalent to rerunning the
full simulation campaign.

## Getting started

Download or clone this repository while preserving its directory
structure. Consult the documentation within `reproducibility/`
for the analysis workflow and required inputs.
